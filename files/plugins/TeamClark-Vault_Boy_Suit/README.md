# Vault Boy Suit

Adds the Vault Boy from Fallout to the game as a wearable suit. Requires the More Suits mod to appear. Requires [MoreSuits](https://thunderstore.io/c/lethal-company/p/x753/More_Suits/) to appear correctly.
