# Classic Suit Restoration
Adds an additional suit similar to the brown suits in the game's announcement teaser. Everyone in the lobby needs to have the mod downloaded or it will cause issues.

By default, the suit will use the texture from Lethal Company's 1st anniversary event in v65. Note that the anniversary suit is NOT actually the original texture, but an official recreation that more closely resembles the new visual style of the game.

There are additional config settings to:
- Add the birthday hat to the anniversary suit
- Use my unofficial recreation of the original suit texture (from earlier versions of the mod)

Zeekerss no longer has access to the original texture file, so it is unlikely it will ever properly see the light of day, unfortunately.
