# HlebWoW

Adds more suits which have team role names and unique decals. Currently added are: Civilian, Commander, Corpsman, Grunt, Mechanic, Medic, Quartermaster, Sergeant, Scientist and Technician.

Requires [MoreSuits](https://thunderstore.io/c/lethal-company/p/x753/More_Suits/).
