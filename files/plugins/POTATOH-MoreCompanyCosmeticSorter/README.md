# MoreCompany Cosmetic Sorter

A quality-of-life addon for MoreCompany's cosmetics menu.Both V73 and V80 compatible.

This mod improves the cosmetics browser by making large cosmetic collections much easier to navigate.

## Features

![](https://files.catbox.moe/9kadb1.png)

- Sorts cosmetics by body slot
  - Head
  - Chest 
  - Hip 
  - Arms 
  - Legs
- Adds visual section headers
- Adds quick category filters
  - All
  - Head
  - Chest
  - Hip
  - Arms
  - Legs
- Adds a **Clear All** button to remove all currently equipped cosmetics at once.

## Why?

When you use multiple cosmetic packs, MoreCompany puts everything into one giant mixed list.
This mod reorganizes the menu so cosmetics are easier to browse and swap.

## Dependencies

- BepInEx
- MoreCompany

## Installation

Install with Thunderstore Mod Manager / r2modman, or place the `.dll` into your `BepInEx/plugins` folder manually.

## Notes

- This mod only changes the cosmetics menu UI and browsing experience.
- It does **not** add any new cosmetics by itself.
- You still need MoreCompany and your cosmetic packs installed normally.
- The **Clear All** button removes all currently equipped cosmetics through MoreCompany's normal toggle flow for better compatibility.

## Recommended use

Best used if you have a lot of cosmetic packs installed and want faster navigation through large cosmetic libraries.
