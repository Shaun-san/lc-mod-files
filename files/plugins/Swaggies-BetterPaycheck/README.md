# Better Paycheck

**Better Paycheck** reformats the "Paycheck!" UI to be a bit more readable and organized. Sold scrap will be displayed as one line per item, showing each of their names and values. Values are color-coded depending on how high it is, and will be shortened if it's too large to display.

This mod is client-sided, so feel free to use wherever you'd like.

Please report any issues to me on discord: `@swaggies`.
