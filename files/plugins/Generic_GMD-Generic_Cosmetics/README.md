Generic Cosmetics is a mod that adds a handful of cosmetics and 1 new suit if you have moresuits. More are planned for the future, I had a lot of fun with making this. Now you can properly look like a minimum wage employee fighting for his life with random BS. I HIGHLY recommend using Simple Company, Equipment Company, and Visor Colors. These mods fit very well with each other (and this one).

# Cosmetics

Most cosmetics are in the image showing the storehouse suit but like theres more.
