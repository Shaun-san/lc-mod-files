# Thighs Cosmetics

This mod features cosmetics I've made for me and my friends to use, uploading them to Thunderstore means others can try them out and that they can be shared easier.

So, you know, net good (I hope).

You can donate/tip here, if you'd like: https://ko-fi.com/wherethighs

This mod relies on having both BepInEx and MoreCompany downloaded to function.

Extract the .zip and put the folder in your Lethal Company folder, or use the Thunderstore Mod Manager (this is much simpler and easier).
