# What does this do?
### *If you've ever used the original RuntimeIcons by itself and found that some items look weird or are facing the wrong way in their icons, then this is for you.*
***
This specifies new rotation angles for *many* different items from the game, as well as items from **over 100 other mods**, to make sure they look nice in the hotbar (Using the built-in overrides system RuntimeIcons has).

# Which mods are supported?

I've set up a [wiki page](https://thunderstore.io/c/lethal-company/p/debit_card_debit/RuntimeIcons_BetterRotations/wiki/5519-supported-mods) listing out everything i've added item rotations for, including the version number of when I did it. If a mod has updated adding more scrap items that I haven't covered yet (or if you know of a scrap mod that i've never seen before), feel free to let me know in the [modding discord](https://discord.com/channels/1168655651455639582/1423086110317346877).

In terms of other icon RuntimeIcons addons, there's [HoneeItemIcons](https://thunderstore.io/c/lethal-company/p/debit_card_debit/HoneeItemIcons/) which features very nice digitally drawn icons by Honee & [BetterRotations_NoMiniIcons](https://thunderstore.io/c/lethal-company/p/debit_card_debit/BetterRotations_NoMiniIcons/), which is a way to remove the "special item" mini-icon that's been applied to certain items from Wesley's Moons, Archipelago Scrap, and a couple others.


Additionally, if you're the creator of a scrap mod & would like to use any of my icons in your mod directly, just ask and i'd be glad to hand them over.
